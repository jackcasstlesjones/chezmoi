# Hyprland `hyprland.conf` → `hyprland.lua` migration & syntax reference

Native Lua config landed in **Hyprland v0.55**. This document is both a
migration guide and a fairly complete syntax reference for the `hl.*` API.

> **Provenance / accuracy note.** The exhaustive field/dispatcher tables below
> are compiled from Hyprland's official example `hyprland.lua`, the official
> wiki (which has migrated to Lua), and a community reference generated by
> reading Hyprland's Lua binding-registration source at **v0.55.4**. The API is
> new and still moving — when an exact field name matters, verify it against the
> wiki (<https://wiki.hypr.land>) or your installed version's example config.

## 1. Migration mechanics (read this first)

- **Config location:** `~/.config/hypr/hyprland.lua`.
- **Selection happens once, at startup.** If `hyprland.lua` exists it is loaded
  _instead of_ `hyprland.conf`. Hyprland decides which format to use only when
  the compositor first starts. A normal `hyprctl reload` will **not** switch
  formats — you must fully quit and restart Hyprland (log out/in or reboot).
  - The escape hatch is `hyprctl reload full-reset`, which recreates the entire
    config context and _can_ switch between hyprlang and Lua. The wiki flags it
    as "don't use unless really necessary."
- **Deprecation timeline:** hyprlang is deprecated as of 0.55 and supported for
  roughly 1–2 more releases, then removed. Migrate deliberately, not in a panic.
- **Back up first, and don't leave both files live:**
  ```sh
  cd ~/.config/hypr
  cp hyprland.conf hyprland.conf.bak
  ```
  Keep the backup as `.bak` so a half-finished `hyprland.lua` can't silently
  shadow a config you know works.
- **Automated first pass (optional):** `hyprmorph` (`luarocks install hyprmorph`)
  is a loss-conscious converter — it keeps comments/order, warns on ambiguous
  constructs, and drops anything it can't translate into `-- TODO` comments.
  Treat its output as a _draft_ and review every TODO against §7–§8.

## 2. The translation model

hyprlang is a bespoke `key = value` / `section { }` format. Lua is a real
language. The rules are consistent:

| hyprlang                                      | Lua                                                                                 |
| --------------------------------------------- | ----------------------------------------------------------------------------------- |
| `section { key = val }`                       | `hl.config({ section = { key = val } })`                                            |
| `section:sub { ... }` (e.g. `input:touchpad`) | nested table                                                                        |
| `col.active_border = ...`                     | `col = { active_border = ... }` _(or a quoted key `["col.active_border"] = "..."`)_ |
| `keyword = a,b,c` (monitor, env, bind, …)     | a dedicated `hl.*()` call                                                           |
| `$VAR = x`                                    | `local VAR = "x"`                                                                   |
| `source = other.conf`                         | `require("other")`                                                                  |
| repeated near-identical lines                 | a Lua `for` loop                                                                    |

Types: strings in `"quotes"`, numbers bare, booleans `true`/`false`,
sub-objects as `{ }` tables. Trailing commas are allowed and encouraged.

## 3. `hl.config()` — settings blocks

Every `foo { }` variable block becomes a key in the table passed to
`hl.config()`. You may call it once with everything, or many times. Available
top-level groups: `general`, `decoration`, `input`, `gestures`, `group`,
`binds`, `debug`, `misc`, `dwindle`, `master`, `scrolling`, `ecosystem`,
`render`, `cursor`, `xwayland`, `opengl`, and more (same names as hyprlang).

**hyprlang**

```ini
general {
    gaps_in = 5
    gaps_out = 20
    border_size = 2
    col.active_border = rgba(33ccffee) rgba(00ff99ee) 45deg
    col.inactive_border = rgba(595959aa)
    layout = dwindle
}
decoration {
    rounding = 10
    active_opacity = 1.0
    blur {
        enabled = true
        size = 3
        passes = 1
    }
    shadow {
        enabled = true
        range = 4
        color = rgba(1a1a1aee)
    }
}
input {
    kb_layout = us
    follow_mouse = 1
    touchpad {
        natural_scroll = false
    }
}
misc {
    disable_hyprland_logo = true
    vfr = true
}
dwindle {
    preserve_split = true
}
```

**Lua**

```lua
hl.config({
    general = {
        gaps_in = 5,
        gaps_out = 20,
        border_size = 2,
        col = {
            active_border = { colors = { "rgba(33ccffee)", "rgba(00ff99ee)" }, angle = 45 },
            inactive_border = "rgba(595959aa)",
        },
        layout = "dwindle",
    },
    decoration = {
        rounding = 10,
        active_opacity = 1.0,
        blur   = { enabled = true, size = 3, passes = 1 },
        shadow = { enabled = true, range = 4, color = "rgba(1a1a1aee)" },
    },
    input = {
        kb_layout = "us",
        follow_mouse = 1,
        touchpad = { natural_scroll = false },
    },
    misc = { disable_hyprland_logo = true, vfr = true },
    dwindle = { preserve_split = true },
})
```

Read a live value back with `hl.get_config("general:gaps_in")`.

### Color forms

- Single color: a string, e.g. `"rgba(595959aa)"`, `"rgb(1a1a1a)"`, or a hex
  integer `0xee1a1a1a` (ARGB).
- Gradient: `{ colors = { "rgba(...)", "rgba(...)" }, angle = 45 }`.
- The dotted hyprlang key still works as a quoted string key if you'd rather do
  a 1:1 port: `["col.active_border"] = "rgba(...) rgba(...) 45deg"`.

## 4. Monitors — `hl.monitor()`

One call per output; calls are cumulative. `output` is required.

**hyprlang**

```ini
monitor = ,preferred,auto,auto
monitor = DP-1,2560x1440@144,0x0,1
monitor = eDP-1,disable
```

**Lua**

```lua
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = "auto" })
hl.monitor({ output = "DP-1", mode = "2560x1440@144", position = "0x0", scale = 1 })
hl.monitor({ output = "eDP-1", disabled = true })
```

Common fields: `output`, `mode` (`"1920x1080@144"`, `"preferred"`, `"highres"`,
`"highrr"`), `position` (`"0x0"`, `"auto"`, `"auto-right"`), `scale`
(number or `"auto"`), `transform` (0–7), `mirror`, `bitdepth` (8/10),
`vrr` (-1..3), `disabled`, `reserved = { top, bottom, left, right }`, plus HDR/
color-management fields (`cm`, `icc`, `sdrbrightness`, `supports_hdr`, …).

## 5. Variables & splitting files

hyprlang `$vars` become plain Lua variables; `source` becomes `require`.

```lua
-- was: $mainMod = SUPER   /   $terminal = kitty
local mainMod  = "SUPER"
local terminal = "kitty"

-- was: source = ~/.config/hypr/binds.conf
require("binds")   -- loads ~/.config/hypr/binds.lua (no extension, no path)
```

`require` runs a Lua module. A `local` in that module is **not** visible to the
caller — share values by making them global (drop `local`) or by returning a
table:

```lua
-- colors.lua
return { accent = "rgba(33ccffee)" }
-- hyprland.lua
local colors = require("colors")
-- use colors.accent
```

## 6. Autostart, env, exec

| hyprlang                         | Lua                                                   |
| -------------------------------- | ----------------------------------------------------- |
| `env = KEY,val`                  | `hl.env("KEY", "val")`                                |
| `exec-once = cmd` (startup only) | inside `hl.on("hyprland.start", function() … end)`    |
| `exec = cmd` (every config load) | `hl.exec_cmd("cmd")` at top level                     |
| `exec-shutdown = cmd`            | inside `hl.on("hyprland.shutdown", function() … end)` |

```lua
hl.env("XCURSOR_SIZE", "24")
hl.env("HYPRCURSOR_SIZE", "24")

hl.on("hyprland.start", function()
    hl.exec_cmd("waybar")
    hl.exec_cmd("hyprpaper")
    hl.exec_cmd("nm-applet")
end)

hl.on("hyprland.shutdown", function()
    hl.exec_cmd("some-cleanup.sh")
end)
```

`hl.env` takes an optional third arg `dbus = true` to also push the var to the
D-Bus activation environment. `hl.exec_cmd` optionally accepts a window-rule
table as a second argument (rules applied to whatever the command spawns).

## 7. Keybinds — `hl.bind()`

```lua
hl.bind(keys, dispatcher, opts?) -> handle
```

- **`keys`** is a single modifier-key string: `"SUPER + Q"`, `"SUPER + SHIFT + left"`,
  `"XF86AudioMute"`, `"SUPER + mouse:272"`. Whitespace around `+` is tolerated;
  the official examples use `" + "`, the source docs use `"SUPER+SHIFT+Q"` — both parse.
- **`dispatcher`** is a closure from `hl.dsp.*` **or** any Lua function.
- **`opts`** is an optional table (the old `bind` flag letters, see below).
- **returns a handle** with `:set_enabled(bool)` so you can toggle binds at runtime.

**hyprlang → Lua examples**

```ini
bind  = $mainMod, Q, exec, kitty
bind  = $mainMod, C, killactive
bind  = $mainMod, V, togglefloating
bind  = $mainMod, J, togglesplit
bind  = $mainMod, left, movefocus, l
bind  = $mainMod, 1, workspace, 1
bind  = $mainMod SHIFT, 1, movetoworkspace, 1
bind  = $mainMod, S, togglespecialworkspace, magic
bindm = $mainMod, mouse:272, movewindow
binde = , XF86AudioRaiseVolume, exec, wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%+
bindl = , XF86AudioMute, exec, wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle
```

```lua
hl.bind(mainMod .. " + Q", hl.dsp.exec_cmd("kitty"))
hl.bind(mainMod .. " + C", hl.dsp.window.close())
hl.bind(mainMod .. " + V", hl.dsp.window.float({ action = "toggle" }))
hl.bind(mainMod .. " + J", hl.dsp.layout("togglesplit"))
hl.bind(mainMod .. " + left", hl.dsp.focus({ direction = "left" }))
hl.bind(mainMod .. " + 1", hl.dsp.focus({ workspace = 1 }))
hl.bind(mainMod .. " + SHIFT + 1", hl.dsp.window.move({ workspace = 1 }))
hl.bind(mainMod .. " + S", hl.dsp.workspace.toggle_special("magic"))
hl.bind(mainMod .. " + mouse:272", hl.dsp.window.drag(), { mouse = true })
hl.bind("XF86AudioRaiseVolume", hl.dsp.exec_cmd("wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%+"), { repeating = true })
hl.bind("XF86AudioMute", hl.dsp.exec_cmd("wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle"), { locked = true })
```

### Bind-flag mapping (the old `bind*` suffix letters → `opts` keys)

| hyprlang suffix         | meaning                        | Lua opt                               |
| ----------------------- | ------------------------------ | ------------------------------------- |
| `bind`                  | normal                         | _(omit opts)_                         |
| `bindm`                 | mouse bind                     | `{ mouse = true }`                    |
| `binde`                 | repeat while held              | `{ repeating = true }`                |
| `bindl`                 | works while locked/inhibited   | `{ locked = true }`                   |
| `bindr`                 | fire on release                | `{ release = true }`                  |
| `bindn`                 | non-consuming (passes through) | `{ non_consuming = true }`            |
| `bindt`                 | transparent to other binds     | `{ transparent = true }`              |
| `bindi`                 | ignore modifiers when matching | `{ ignore_mods = true }`              |
| `bindd`                 | with description               | `{ description = "…" }`               |
| combined, e.g. `bindle` | locked + repeat                | `{ locked = true, repeating = true }` |

Other `opts` keys: `click`, `drag`, `long_press`, `auto_consuming`,
`dont_inhibit`, `submap_universal`, and per-device scoping:
`device = { inclusive = true, list = { "dev-name" } }`.

### Loops instead of copy-paste

```lua
for i = 1, 10 do
    local key = i % 10 -- 10 → key "0"
    hl.bind(mainMod .. " + " .. key,          hl.dsp.focus({ workspace = i }))
    hl.bind(mainMod .. " + SHIFT + " .. key,  hl.dsp.window.move({ workspace = i }))
end
```

### Lua-function binds (multiple actions / conditionals)

A bind's action can be a function. Use `hl.dispatch(...)` inside it to run
dispatchers. **Handlers must not block** — they run on the compositor event
loop, so no `io.popen`, network, sleeps, or clipboard tools inside. Use
`hl.dsp.exec_cmd` for external commands.

```lua
hl.bind("SUPER + Tab", function()
    hl.dispatch(hl.dsp.window.cycle_next())
    hl.dispatch(hl.dsp.window.bring_to_top())
end)

hl.bind("SUPER + X", function()
    local w = hl.get_active_window()
    if w ~= nil and w.title == "htop" then
        hl.dispatch(hl.dsp.window.float({ action = "set" }))
    else
        hl.dispatch(hl.dsp.window.float({ action = "toggle" }))
    end
end)
```

### Submaps

hyprlang `submap = name … submap = reset` becomes `hl.define_submap`, and you
enter/leave with the `submap` dispatcher.

```lua
hl.define_submap("resize", function()
    hl.bind("left",  hl.dsp.window.resize({ x = -10, y = 0, relative = true }))
    hl.bind("right", hl.dsp.window.resize({ x =  10, y = 0, relative = true }))
    hl.bind("Escape", hl.dsp.submap("default"))
end)
hl.bind("SUPER + R", hl.dsp.submap("resize"))
```

### Unbinding

```lua
hl.unbind("SUPER + Q")   -- remove one
hl.unbind("all")         -- clear everything
```

`hl.dsp.*` functions **return dispatcher closures**; they don't act
immediately. Feed them to `hl.bind()` or `hl.dispatch()`.

### `hl.dsp.focus({ ... })` modes

`{ direction = "left"/"right"/"up"/"down" }` · `{ monitor = "DP-1"/"+"/"-"/"next"/"prev" }` ·
`{ workspace = "3"/"name:chat", on_current_monitor = true }` ·
`{ window = "class:…"/"title:…"/"address:0x…" }` · `{ last = true }` · `{ urgent_or_last = true }`.

### `hl.dsp.window.*`

`close` · `kill` · `signal({ signal })` · `float({ action, window })` ·
`fullscreen({ mode, action })` · `fullscreen_state({ internal, client, action })` ·
`pseudo` · `move({ … })` · `swap({ … })` · `center` · `cycle_next({ next, tiled, floating })` ·
`tag({ tag })` · `clear_tags` · `toggle_swallow` · `pin({ action })` · `bring_to_top` ·
`alter_zorder({ mode = "top"/"bottom"/"up"/"down" })` · `set_prop({ prop, value })` ·
`deny_from_group({ action })` · `drag` · `resize({ x, y, relative = true })`.

**`window.move()` modes:** `{ direction = "left" }` · `{ x, y, relative = true }` ·
`{ workspace = "3"/"special:magic", follow = true }` · `{ monitor = "+" , follow = true }` ·
`{ into_group = "left" }` · `{ into_or_create_group = "left" }` · `{ out_of_group = true }`.

### `hl.dsp.workspace.*`

`rename({ workspace, name })` · `move({ workspace?, monitor })` ·
`swap_monitors({ monitor1, monitor2 })` · `change_id({ workspace, id })` ·
`toggle_special(name?)`.

### `hl.dsp.group.*`

`toggle` · `next` · `prev` · `active({ index })` · `move_window({ forward })` ·
`lock({ action })` · `lock_active({ action })`.

### `hl.dsp.cursor.*`

`move_to_corner({ corner = 1..4 })` · `move({ x, y })`.

### Top-level dispatchers

`exec_cmd(cmd)` · `exec_raw(cmd)` (no shell quoting) · `exit()` · `submap(name)` ·
`pass({ window })` · `send_shortcut({ mods, key, window })` ·
`send_key_state({ mods, key, state })` · `layout(msg)` · `dpms({ action, monitor })` ·
`event(msg)` · `global(msg)` · `force_renderer_reload()` · `force_idle(timeout)` ·
`focus({ … })` · `no_op()`.

> DPMS / force-idle should not be bound directly — wrap them in a short
> `hl.timer(...)` from inside a function bind to avoid undefined behavior.

## 9. Window rules — `hl.window_rule()`

```lua
hl.window_rule({ name?, enabled?, match = { … }, <effect> = <value>, … }) -> handle
```

`windowrulev2` collapses into a single call: a `match` table for selectors and
top-level keys for effects. A `name` lets you re-call to update it, and the
handle supports `:set_enabled(false)`.

**hyprlang**

```ini
windowrulev2 = suppressevent maximize, class:.*
windowrulev2 = float, class:^(pavucontrol)$
windowrulev2 = size 800 600, class:^(pavucontrol)$
windowrulev2 = opacity 0.9 0.8, class:^(kitty)$
windowrulev2 = workspace 3, class:^(firefox)$
```

**Lua**

```lua
hl.window_rule({
    name = "suppress-maximize",
    match = { class = ".*" },
    suppress_event = "maximize",
})

hl.window_rule({
    name = "pavu",
    match = { class = "^(pavucontrol)$" },
    float = true,
    size = "800 600",
})

hl.window_rule({ name = "kitty-opacity", match = { class = "^(kitty)$" }, opacity = "0.9 0.8" })
hl.window_rule({ name = "ff-ws", match = { class = "^(firefox)$" }, workspace = "3" })
```

**`match` selectors:** `class`, `title`, `initialClass`, `initialTitle`, `tag`,
`pid`, `address`, `xwayland` (bool), `float` (bool), `fullscreen` (bool),
`pin` (bool), `workspace`, `monitor`, `grouped` (bool), `swallowing` (bool).

**Effects (top-level keys)** — the big ones:
`float` · `tile` · `fullscreen` · `maximize` · `center` · `pseudo` · `pin` ·
`move` (`"100 200"`, `"100 monitor_w-100"`) · `size` (`"500x500"`, `"50% 50%"`) ·
`min_size` / `max_size` · `monitor` · `workspace` · `group` (`"set"/"unset"/"toggle"`) ·
`suppress_event` · `rounding` · `border_size` · `border_color` · `opacity` ·
`animation` · `tag` · `idle_inhibit` (`"none"/"always"/"focus"/"fullscreen"`) ·
`no_initial_focus` · `no_focus` · `no_anim` · `no_blur` · `no_shadow` · `no_dim` ·
`dim_around` · `opaque` · `decorate` · `keep_aspect_ratio` · `nearest_neighbor` ·
`immediate` (tearing) · `xray` · `render_unfocused` · `stay_focused` ·
`no_screen_share` · `no_vrr` · `confine_pointer` · `persistent_size` · `tonemap`.
(That's most of them; a handful of niche ones exist — check the wiki if you use
something exotic.)

## 10. Layer rules — `hl.layer_rule()`

`layerrule` → `hl.layer_rule`, matching on `namespace` (regex).

**hyprlang**

```ini
layerrule = blur, ^(waybar)$
layerrule = ignorezero, ^(waybar)$
layerrule = noanim, ^(wofi)$
```

**Lua**

```lua
hl.layer_rule({ name = "waybar-blur", match = { namespace = "^(waybar)$" }, blur = true, ignore_alpha = 0 })
hl.layer_rule({ name = "wofi-noanim", match = { namespace = "^(wofi)$" }, no_anim = true })
```

Effects: `no_anim`, `blur`, `blur_popups`, `ignore_alpha` (0–1), `dim_around`,
`xray`, `animation`, `order`, `above_lock` (0–2), `no_screen_share`.

## 11. Workspace rules — `hl.workspace_rule()`

**hyprlang**

```ini
workspace = 1, monitor:DP-1, default:true
workspace = w[tv1], gapsout:0, gapsin:0
workspace = special:magic, on-created-empty:kitty
```

**Lua**

```lua
hl.workspace_rule({ workspace = "1", monitor = "DP-1", default = true })
hl.workspace_rule({ workspace = "w[tv1]", gaps_out = 0, gaps_in = 0 })
hl.workspace_rule({ workspace = "special:magic", on_created_empty = "kitty" })
```

Fields: `workspace` (selector), `monitor`, `default`, `persistent`, `gaps_in`,
`gaps_out`, `float_gaps`, `border_size`, `no_border`, `no_rounding`, `decorate`,
`no_shadow`, `on_created_empty`, `default_name`, `layout`, `animation`,
`layout_opts` (table), `enabled`.

## 12. Per-device input — `hl.device()`

**hyprlang**

```ini
device {
    name = epic-mouse-v1
    sensitivity = -0.5
    accel_profile = flat
}
```

**Lua**

```lua
hl.device({ name = "epic-mouse-v1", sensitivity = -0.5, accel_profile = "flat" })
```

Get the exact `name` from `hyprctl devices`. Fields include `enabled`,
`sensitivity` (-1..1), `accel_profile` (`"adaptive"/"flat"`), `natural_scroll`,
`tap_to_click`, `tap_and_drag`, `drag_lock`, `left_handed`, `scroll_method`,
`scroll_button`, `scroll_factor`, `middle_button_emulation`, `tap_button_map`,
`disable_while_typing`, `numlock_by_default`, the `kb_*` family
(`kb_layout`/`kb_variant`/`kb_options`/`kb_rules`/`kb_model`/`kb_file`),
`repeat_rate`, `repeat_delay`, and tablet-specific fields (`transform`,
`output`, `region_position`, `region_size`, `active_area_*`, `flip_x`/`flip_y`).

## 13. Gestures — `hl.gesture()`

Replaces the newer `gesture =` lines (and old `workspace_swipe*` intent).

**hyprlang**

```ini
gesture = 3, horizontal, workspace
gesture = 4, up, fullscreen
```

**Lua**

```lua
hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })
hl.gesture({ fingers = 4, direction = "up", action = "fullscreen" })
```

Fields: `fingers` (2–9), `direction`
(`"horizontal"/"vertical"/"left"/"right"/"up"/"down"/"any"`), `action`
(`"workspace"/"resize"/"move"/"special"/"close"/"float"/"fullscreen"/"cursor_zoom"/"scroll_move"/"unset"`,
or a Lua function), plus `mods`, `scale`, `disable_inhibit`, `zoom_level`,
`workspace_name`, `mode`.

## 14. Animations, curves, colors

**hyprlang**

```ini
bezier = easeOutQuint, 0.23, 1, 0.32, 1
animation = windows, 1, 4.79, easeOutQuint
animation = windowsIn, 1, 4.1, easeOutQuint, popin 87%
animation = global, 1, 10, default
```

**Lua**

```lua
-- bezier control points grouped into {x, y} pairs:
hl.curve("easeOutQuint", { type = "bezier", points = { {0.23, 1}, {0.32, 1} } })
-- springs are first-class:
hl.curve("easy", { type = "spring", mass = 1, stiffness = 71.2633, dampening = 15.8273644 })

-- "1" (the enabled flag) becomes enabled = true; use bezier= OR spring=; style optional:
hl.animation({ leaf = "windows",   enabled = true, speed = 4.79, bezier = "easeOutQuint" })
hl.animation({ leaf = "windowsIn", enabled = true, speed = 4.1,  bezier = "easeOutQuint", style = "popin 87%" })
hl.animation({ leaf = "windows",   enabled = true, speed = 4.79, spring = "easy" })
hl.animation({ leaf = "global",    enabled = true, speed = 10,   bezier = "default" })
```

Leaves include `global`, `border`, `borderangle`, `windows`, `windowsIn`,
`windowsOut`, `fade`, `fadeIn`, `fadeOut`, `layers`, `layersIn`, `layersOut`,
`workspaces`, `workspacesIn`, `workspacesOut`, `zoomFactor`, etc. `default` is a
built-in curve you can reference without defining it.

## 15. Permissions & plugins

```lua
hl.config({ ecosystem = { enforce_permissions = true } })
hl.permission("/usr/(bin|local/bin)/grim", "screencopy", "allow")
hl.permission("/usr/(lib|libexec|lib64)/xdg-desktop-portal-hyprland", "screencopy", "allow")
hl.permission("/usr/(bin|local/bin)/hyprpm", "plugin", "allow")
```

`type` ∈ `"screencopy"/"cursorpos"/"plugin"/"keyboard"`; `mode` ∈
`"allow"/"deny"/"ask"`. Permission changes need a full restart, not a reload.

Plugins (was `plugin = /path.so`):

```lua
hl.plugin.load("/absolute/path/to/plugin.so")
```

## 16. New superpowers (no hyprlang equivalent)

These are the reason to bother migrating. They let the config react to the
running desktop.

### Events — `hl.on(event, cb)` / `hl.off(sub)`

```lua
local sub = hl.on("window.open", function(win)
    hl.print("opened:", win.class, win.title)
end)
-- sub:remove()  -- or hl.off(sub)
```

Event names include: `window.open` / `open_early` / `close` / `destroy` /
`kill` / `active` / `urgent` / `title` / `class` / `pin` / `fullscreen` /
`move_to_workspace`; `layer.opened` / `closed`; `workspace.active` / `created` /
`removed` / `special_active` / `move_to_monitor`; `monitor.added` / `removed` /
`focused` / `layout_changed`; `config.reloaded` / `props_refreshed`;
`keybinds.submap`; `screenshare.state`; `hyprland.start` / `hyprland.shutdown`;
`input.keyboard.key`.

### Timers — `hl.timer(cb, { timeout, type })`

```lua
local t = hl.timer(function() hl.print("tick") end, { timeout = 1000, type = "repeat" })
-- t:cancel()
-- type = "oneshot" for a single delayed call
```

### Query functions — `hl.get_*()`

`hl.get_active_window()` · `hl.get_windows({ class=, workspace=, floating= })` ·
`hl.get_window(sel)` · `hl.get_workspaces()` · `hl.get_active_workspace(mon?)` ·
`hl.get_monitors()` · `hl.get_active_monitor()` · `hl.get_monitor_at_cursor()` ·
`hl.get_cursor_pos()` · `hl.get_current_submap()` · `hl.version()`.

Objects have rich properties, e.g. an `HL.Window` exposes `class`, `title`,
`floating`, `pid`, `at`, `size`, `workspace`, `monitor`, `tags`, `active`, `group`;
`HL.Monitor` has `set_workspace({ workspace })`, `reserved`, `available_modes`,
scale/transform, etc.

### Notifications — `hl.notification.create()`

```lua
local n = hl.notification.create({ text = "Reloaded", timeout = 2000, icon = "ok" })
-- n:set_text("…"); n:dismiss()
```

`icon` ∈ `"warning"/"info"/"error"/"ok"/"hint"/"confused"/"question"/"none"`.

### Custom layouts — `hl.layout.register(name, methods)`

Register a Lua tiling layout by implementing lifecycle callbacks
(`onWindowAdded`, `onWindowRemoved`, `recalculate`, `resizeActiveWindow`, …).
Overkill for a straight migration, but it exists.

## 17. A complete worked config

```lua
-- ~/.config/hypr/hyprland.lua

------------------------------------------------------------------ variables
local mainMod  = "SUPER"
local terminal = "kitty"
local menu     = "wofi --show drun"

------------------------------------------------------------------ monitors
hl.monitor({ output = "", mode = "preferred", position = "auto", scale = "auto" })

------------------------------------------------------------------ env
hl.env("XCURSOR_SIZE", "24")

------------------------------------------------------------------ autostart
hl.on("hyprland.start", function()
    hl.exec_cmd("waybar")
    hl.exec_cmd("hyprpaper")
    hl.exec_cmd("nm-applet")
end)

------------------------------------------------------------------ look & feel
hl.config({
    general = {
        gaps_in = 5, gaps_out = 20, border_size = 2,
        col = {
            active_border = { colors = { "rgba(33ccffee)", "rgba(00ff99ee)" }, angle = 45 },
            inactive_border = "rgba(595959aa)",
        },
        layout = "dwindle",
    },
    decoration = {
        rounding = 10,
        blur = { enabled = true, size = 3, passes = 1 },
        shadow = { enabled = true, range = 4, color = "rgba(1a1a1aee)" },
    },
    input = { kb_layout = "us", follow_mouse = 1, touchpad = { natural_scroll = false } },
    misc  = { disable_hyprland_logo = true, vfr = true },
    dwindle = { preserve_split = true },
})

hl.curve("easeOutQuint", { type = "bezier", points = { {0.23, 1}, {0.32, 1} } })
hl.animation({ leaf = "windows", enabled = true, speed = 4.79, bezier = "easeOutQuint" })

------------------------------------------------------------------ binds
hl.bind(mainMod .. " + Q", hl.dsp.exec_cmd(terminal))
hl.bind(mainMod .. " + R", hl.dsp.exec_cmd(menu))
hl.bind(mainMod .. " + C", hl.dsp.window.close())
hl.bind(mainMod .. " + V", hl.dsp.window.float({ action = "toggle" }))
hl.bind(mainMod .. " + J", hl.dsp.layout("togglesplit"))
hl.bind(mainMod .. " + left",  hl.dsp.focus({ direction = "left" }))
hl.bind(mainMod .. " + right", hl.dsp.focus({ direction = "right" }))
hl.bind(mainMod .. " + up",    hl.dsp.focus({ direction = "up" }))
hl.bind(mainMod .. " + down",  hl.dsp.focus({ direction = "down" }))

for i = 1, 10 do
    local key = i % 10
    hl.bind(mainMod .. " + " .. key,         hl.dsp.focus({ workspace = i }))
    hl.bind(mainMod .. " + SHIFT + " .. key, hl.dsp.window.move({ workspace = i }))
end

hl.bind(mainMod .. " + S", hl.dsp.workspace.toggle_special("magic"))
hl.bind(mainMod .. " + mouse:272", hl.dsp.window.drag(),   { mouse = true })
hl.bind(mainMod .. " + mouse:273", hl.dsp.window.resize(), { mouse = true })

hl.bind("XF86AudioRaiseVolume", hl.dsp.exec_cmd("wpctl set-volume -l 1 @DEFAULT_AUDIO_SINK@ 5%+"), { locked = true, repeating = true })
hl.bind("XF86AudioLowerVolume", hl.dsp.exec_cmd("wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-"),      { locked = true, repeating = true })
hl.bind("XF86AudioMute",        hl.dsp.exec_cmd("wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle"),     { locked = true })

------------------------------------------------------------------ rules
hl.window_rule({ name = "suppress-maximize", match = { class = ".*" }, suppress_event = "maximize" })
hl.window_rule({ name = "pavu-float",        match = { class = "^(pavucontrol)$" }, float = true })
hl.layer_rule({  name = "waybar-blur",       match = { namespace = "^(waybar)$" }, blur = true })
hl.workspace_rule({ workspace = "special:magic", on_created_empty = terminal })
```

## 18. Testing, REPL, and rollback

**1. Lint the Lua before you log out** (stub `hl` so you only catch syntax/typos):

```sh
lua -e 'hl=setmetatable({},{__index=function() return function() return setmetatable({},{__index=function() return function() end end}) end end}); dofile(os.getenv("HOME").."/.config/hypr/hyprland.lua")'
```

**2. Switch over** by fully restarting Hyprland (log out/in or reboot). Reload
alone won't change formats. In a pinch, from a running session:

```sh
hyprctl reload full-reset    # recreates config context; can switch conf<->lua
```

**3. Probe the live API** while iterating (great for figuring out selectors and
values):

```sh
hyprctl repl 'hl.get_active_window().class'
hyprctl repl 'for i,w in pairs(hl.get_windows()) do print(i, w.class) end'
hyprctl dispatch 'hl.dsp.focus({ workspace = "3" })'
hyprctl eval 'hl.notification.create({ text = "hi", timeout = 1500 })'
```

**4. Roll back** from a TTY (`Ctrl+Alt+F3`) if something's broken:

```sh
mv ~/.config/hypr/hyprland.lua ~/.config/hypr/hyprland.lua.wip
# restart Hyprland → back on hyprland.conf
```
